# TC-005. Добавление задачи длиной 201 символ

**Требование:** REQ-02
**Тип:** Граничный
**Приоритет:** Высокий
	
## Предусловия
Приложение открыто, список задач пуст.

## Шаги
1. Ввести текст «Купить хлеб, пока магазин открыт. Выйти из дома за 20 минут до закрытия, взять деньги и пакет. Успеть вернуться до дождя..»
2. Нажать «Добавить»

## Ожидаемый результат
Ошибка "Превышен лимит символов"
